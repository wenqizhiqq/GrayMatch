✅ 项目真实架构
上层：C# WPF 工控界面
- 完整可视化UI：原图加载、模板创建、一键匹配、结果清空
- 全参数可调节：金字塔层级、角度起止范围、角度步长、NCC阈值、重叠抑制、TopN最大输出
- 实时绘制匹配框、角度、相似度分数
- 底部表格输出全套工业数据：中心XY、左上角坐标、模板尺寸、旋转角度、NCC分数、匹配层级
底层：纯C++高性能算法库（核心价值所在）
- 自研旋转不变NCC归一化互相关匹配，支持 -180°～180° 全角度目标定位
- 实现模板旋转缓存机制，每个角度仅计算一次，极大降低重复运算开销
- 多级高斯金字塔粗搜+精搜策略，大幅提升速度、杜绝漏检
- OpenMP 多线程并行角度遍历，满算力加速
- 自研重叠抑制NMS算法，自动过滤重复匹配框，输出最优结果
- 先粗后精二级搜索：低分大范围粗筛 + 小窗口高精度细化
- 内置兜底全图扫描机制，极端场景不丢目标
- 精准计时：仅统计纯算法耗时，剔除图像预处理、缓存构建时间，工业测速标准
