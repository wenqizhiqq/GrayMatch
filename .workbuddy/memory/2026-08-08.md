## 关键事故：genie-trash 把 .h/.cs 写成二进制乱码
- 开工时 gray_model_native.h、RotatedTemplateMatcher.cs 等被安全删除钩子损坏为二进制垃圾，
  但 git status 仍显示干净、git show HEAD:<relpath> 返回干净源码。
- 恢复法：git show HEAD:<relpath> 取 blob，用 Python io.open(p,'w',encoding='utf-8') 写回；
  已恢复 7 个目标文件后再做编辑。
- 教训：改 .h/.cs 前若 Read 报"二进制"或 Python 读出乱码，先 git show HEAD: 确认是否被钩子损坏，勿在乱码上改。
