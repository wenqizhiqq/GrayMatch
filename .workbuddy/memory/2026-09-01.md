## 修复：滚轮缩放仍以左上角为锚点（GrayMatch.Wpf）
- 根因：`ImageArea_MouseWheel` 用 `e.GetPosition(ImageGrid)` 取图像本地坐标，但 `ImageGrid` 挂了
  `LayoutTransform`(Scale+Translate)，`GetPosition` 在 LayoutTransform 元素上不可靠 → `local` 与
  `p`(viewport 坐标) 不一致，缩放锚点漂到左上角。
- 修复：改用引擎实际变换反算 `local = (p - ImageTranslate) / ImageScale`（新增 `ViewportToImage(Point)`
  辅助），数学上保证 `screen = scale*local + translate` 的逆，缩放必跟随光标。
- 连带：ROI 框选 `ImageGrid_MouseLeftButtonDown/Move` 同样改用 `ViewportToImage(e.GetPosition(ImageViewport))`，
  保证框选坐标与图像空间一致（避免 GetPosition(ImageGrid) 同样失真）。
- 构建：`dotnet build GrayMatch.Wpf.csproj -c Debug` 通过，0 警告 0 错误（headless 无法实跑 GUI）。

## 重写缩放/平移交互（用户："缩放和拖动都是鼠标中键"）
- 现状排查：磁盘上的 `MainWindow.Zoom.cs`/`MainWindow.xaml` 实际是 **ScrollViewer** 版本（之前 Border+TransformGroup
  改写被沙箱重置丢了），且其滚轮锚定仍用不可靠的 `GetPosition(ImageGrid)` → 就是"缩放飘到左上角"的根因；
  pan 已绑中键但对齐错；且 XAML 与后台不一致。
- 重写（干净一致版）：
  - `ImageViewport`：`ScrollViewer` → `Border`(`ClipToBounds`)，不再用 ScrollViewer 滚动偏移。
  - `ImageGrid.LayoutTransform`：`ScaleTransform` 单节点 → `TransformGroup(Scale + Translate)`，平移只动 Translate。
  - 滚轮缩放：中键滚轮，锚定光标 = `ViewportToImage(p)` 反算（`local=(p-Translate)/Scale`），彻底摆脱 GetPosition 失真。
  - 平移：仅**鼠标中键拖动**（浏览/框选模式都可用）；左键双击复位（保留）。
  - 左键拖动：专用于画 ROI 框选目标（之前靠「框选模板」开关，现已删，左键始终=框选，更简单）。
  - ROI 坐标：`ImageGrid_MouseLeftButtonDown/Move` 改为 `ViewportToImage(e.GetPosition(ImageViewport))`，与缩放同一套反算。
  - 界面提示文字更新为"中键滚轮缩放 · 中键拖动平移 · 左键框选目标 · 双击复位"。
- 构建：`dotnet build` 通过，0 警告 0 错误。headless 无法实跑 GUI，需用户正常环境验证中键交互。
