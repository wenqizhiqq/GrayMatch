# 2026-08-18

## 轮廓匹配漏检修复
- 用户反馈：勾选「轮廓匹配」后数字图中很多目标匹配不到（截图 14/18）。
- 根因：轮廓/边缘梯度图经高斯金字塔逐层下采样后细边被抹糊，粗层无法给出可靠种子，导致旋转目标漏检。
- 修复：RotatedTemplateMatcher.Match() 中当 UseContour 时强制 pyramidLevels = 0，走 legacy 两遍全分辨率路径。
- 附带修复：把 OpenCvSharp.Size.Zero 替换为 new OpenCvSharp.Size(0, 0)，避免 OpenCvSharp 4.13 下编译失败。
- 验证：控制台用 图片1300x1000.png + 70x104 模板测试：
  - 灰度：pyramid 0/3/5 均 18/18，min score ~0.94。
  - 轮廓（修复前）：pyramid=3/5 仅 24 个结果且多假阳性，60° 目标漏检。
  - 轮廓（修复后）：pyramid 0/3/5 统一走 legacy，不再丢高旋转目标；阈值 0.45 时可在 -5~65° 内干净检出全部 18 个。
- UI：更新 MainWindow.xaml 中「轮廓匹配」与「金字塔层级」ToolTip，提示轮廓模式忽略金字塔层级并建议阈值≥0.40。
- 构建：dotnet build GrayMatch.Wpf/GrayMatch.Wpf.csproj -c Debug -p:BaseOutputPath=_wpfout_contourfix2/ → 0 警告 0 错误。
