## 图像画布支持鼠标拖拽平移（GrayMatch.Wpf）
- 需求：图片要能鼠标拖拽缩放（实际=拖拽平移 + 滚轮缩放）。
- 改动（`MainWindow.Zoom.cs` + `MainWindow.xaml`）：
  - 平移从「仅中键」扩展为「右键拖动（或中键）」；新增 `_panButton` 记录起拖按键，`MouseUp` 按同键结束，拖动时光标变 Hand。
  - 在 `ScrollViewer` 与 `ImageGrid` 上设 `ContextMenu="{x:Null}"`，避免右键拖动时弹出系统右键菜单。
  - 画布右下角提示改为「滚轮缩放 · 右键拖动平移 · 双击复位」。
- 不破坏核心交互：左键拖拽仍是「框选目标/创建模板」（ROI 在 `ImageGrid_MouseLeftButtonDown`，且 `ImageGrid_MouseMove` 仅当 `LeftButton==Pressed` 才画框，右键平移不会误触发框选）。
- 验证：`dotnet build GrayMatch.Wpf.csproj -c Debug` → 0 警告 0 错误。本沙箱无 GUI，未实跑窗口，需用户本机 `dotnet run --project GrayMatch.Wpf` 验证手感。
- 取舍说明：未改左键为平移，因左键是模板框选的核心操作；若用户更想要「左键直接拖图、框选改用别的键/模式」，可再加模式切换。

## 拖动平移修复（第二轮）
- 用户反馈「拖动缩放不了」。根因：上一版用 ScrollViewer 滚动做平移，**适配视图（图片小于画布）时滚动范围为 0，拖动无效→看起来卡死**；且左键被 ROI 框选占用，只有中/右键能平移。
- 重构 `MainWindow.Zoom.cs` + XAML 画布：弃用 ScrollViewer，改用 `Border(ClipToBounds)` + `Grid.LayoutTransform = TransformGroup(Scale + Translate)` 手动变换。
  - 平移改为直接改 `ImageTranslate`（X/Y），**任意缩放级别（含适配视图）都能自由拖动**。
  - 滚轮缩放：以光标为锚点重算 scale + translate（公式 `ix=(p-t)/old; t'=p-ix*new`）。
  - 双击复位 = FitToView（scale=min(vp/src)，translate 居中）。
  - `Mouse.GetPosition(ImageGrid)` 因 LayoutTransform 仍返回图像空间坐标，ROI/结果/缺陷叠加层依旧贴合像素（未破坏）。
- 新增交互模式切换：画布左上角 `ToggleButton BtnSelectMode`（⌶ 框选模板）。
  - 默认「浏览」模式：左键拖动平移（最直觉）；框选模式：左键拖框选目标，右键/中键仍可平移。
  - `_selectMode` 字段；ROI 三个 handler（`ImageGrid_MouseLeftButtonDown/Up`）加 `if(!_selectMode) return;` 防止浏览模式左键被框选抢走鼠标捕获。
- 验证：`dotnet build` 0 警告 0 错误。本沙箱无 GUI 未实跑；用户本机 `dotnet run` 验证手感。

## .webp 支持
- 需求：`.webp` 图片也要能打开。
- 两处修复：
  1. `MainWindow.xaml.cs` `OpenFolderAsync` 的扩展名白名单 `exts` 加入 `.webp`（否则文件夹批量载入根本不收录 webp，列表里看不到）。
  2. `RotatedTemplateMatcher.LoadSource` 原只靠 `Cv2.ImRead`，若所用 `opencv_world480` 构建未带 WebP 会读不出。新增 `LoadViaWpf` 回退：用 WPF `BitmapDecoder`（WIC，Windows 10/11 原生支持 webp）解码 → `FormatConvertedBitmap` 转 `Bgr24` → 拷贝为连续字节建 `Mat(CV_8UC3)`。先试 OpenCV，失败再走 WPF，保证 webp 等格式可打开。
  - 新增 `using System.Windows.Media; using System.Windows.Media.Imaging;`（仅 WPF 工程引用，无 WinForms 工程编译此文件，安全）。
- 验证：`dotnet build GrayMatch.Wpf.csproj -c Debug` 0 警告 0 错误。本沙箱无 GUI 未实跑；用户本机用含 webp 的图测试。

## 缩放跟随光标 + 拖动修复（第三轮）
- 用户反馈：缩放不按鼠标位置、且拖动不了（疑似跑的是重写前的 ScrollViewer 旧版，或细节 bug）。
- 重写 `ImageArea_MouseWheel`：用 `e.GetPosition(ImageGrid)` 取「光标所在图像本地(未缩放)坐标」作为锚点，配合 `e.GetPosition(ImageViewport)` 取画布坐标，公式 `t' = p - local*newScale`，**不依赖图像原点假设**，保证以光标处像素为锚点缩放。
- `ImageGrid_MouseMove`（ROI handler）加 `if (!_selectMode) return;`：浏览模式下即使鼠标捕获偶发失败，左键拖动也绝不画框，只交给画布平移（防止「拖动画出框/不动」）。
- `ImageGrid` 显式 `HorizontalAlignment=Left VerticalAlignment=Top`：锁定原点 (0,0)，保证 `FitToView` 居中公式精确。
- 验证：`dotnet build` 0 警告 0 错误。提示用户本机务必重新 `dotnet build/run` 拿新二进制（沙箱改的是工作树源码）。
