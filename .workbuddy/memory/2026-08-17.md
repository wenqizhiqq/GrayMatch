## 把「药名匹配配方」默认值写进 XAML（用户要求）
- 用户：把上轮定的「配方」参数直接写进 WPF 界面默认值。
- 配方 = 灰度模式（关轮廓）+ 147x502 药名竖条模板 + `Match(3,-45,45,2,0.30,0.25,20)`。
- `GrayMatch.Wpf/MainWindow.xaml` 改默认（6 个数值）：
  - `TbAngleStart` "-180"→"-45"；`TbAngleEnd` "180"→"45"；`TbAngleStep` "1"→"2"；
  - `TbThreshold` "0.5"→"0.30"；`TbOverlap` "0.1"→"0.25"；`TbTopN` "200"→"20"。
  - 金字塔 `CmbPyramid` SelectedIndex 已=3（代码按 ComboBoxItem 内容直接解析为 pyramidLevels=3，与配方一致，无需改）；`ChkContour` 已 IsChecked=False（灰度）；`ChkDense` False；Scale/Deform 滑块已=0。
- 代码级默认也同步：`MainWindow.xaml.cs` 的 `MatchSettings` 默认值改为 AngleStart=-45/End=45/Step=2/Threshold=0.30/Overlap=0.25/TopN=20（Overlap 本就是 0.25）。原因：这些参数会被序列化到 `settings.json`（`AppDataDir/settings.json`）并**启动时回填覆盖 XAML 默认值**——只改 XAML 不够，老用户机器上旧 settings.json 会盖掉。
- 构建验证：`dotnet build GrayMatch.Wpf -c Debug`（移开锁定 obj + `-p:BaseOutputPath` 重定向）**0 错误 3 警告**（NU1900 是沙箱 NuGet 漏洞库联网失败，无害）。
- 给用户提醒：若之前在本机跑过该 App，需删掉 `settings.json`（或手动在 UI 里把参数改一遍）才能用上新默认值；沙箱 push 仍 401，需用户 VS Rebuild + 本机验证。
