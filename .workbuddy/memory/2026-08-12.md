## 踩坑（重要，复用价值高）
1. **积分图双重累加 bug（最致命）**：原先行前缀循环已用 `II[(y+1)*SW+(x+1)] = II[y*SW+(x+1)] + rs` 递归完成整张 2D 积分，又叠加了一遍 SSE2 列累加 → 积分图指数级膨胀、float 溢出为负，`varI` 变 -1.7e11，NCC 全丢。修复：行循环改为纯行前缀 `= rs`，列累加交给 SSE2 垂直 pass。
2. **NCC 居中数学**：模板在 FFT 前已居中（Tc=T-meanT），`num=IFFT(specI·conj(specT))` 直接等于居中分子，`ncc = num/(√varI·√varT)` 正确；**不要**再减 `N·meanT·meanI`（那是错误方向）。
3. **旋转符号约定**：`rotateTemplate` 必须 `sx=dx*c+dy*s`、`sy=-dx*s+dy*c`（CCW +ang），与 OpenCV `getRotationMatrix2D(center,+angle,1)` 一致，否则勾选框开/关时报告角度相反。
4. **SSE2 复数共轭乘**：`specC=specI*conj(specT)` 的 shuffle 写法（`_MM_SHUFFLE(2,0,2,0)` 取 re、`(3,1,3,1)` 取 im，`_mm_unpacklo_ps(re,im)` 打包）经验证正确，已 `#if 1` 启用。
5. 独立正确性测试 `fastcpp_test.cpp`（不含 OpenCV）：平移单测 score=1.0；旋转 0..360 step3 扫 186ms（/openmp），峰值在 36°≈37°，别名 126/216/306（加号 4 重对称），ALL TESTS PASSED。
