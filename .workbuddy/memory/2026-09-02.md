- git 提交跨轮不持久：每轮 `master` 复位到 `9f8e10d`（"水印"），working tree 也复位。故无法靠 commit 落盘，deliverable 直接给文件。

## 运行报错修复 + 缺陷参数持久化补齐
- 用户截图反馈运行抛 `InvalidOperationException: 无法绑定 ContentPresenter 的属性，因为类型 ToggleButton 上没有名为 Header 的属性`。根因：FriendlyExpander 模板内层 `ToggleButton.ControlTemplate` 误用 `ContentSource="Header"`（这是 Expander 的概念），而 ToggleButton 应绑定 `Content="{TemplateBinding Header}"`，内部 ContentPresenter 用 `Content="{TemplateBinding Content}"`。
